
# SVG Visual Language — v0.1

## 1. Design Identity

Create editorial-style SVG infographics that combine
structured information with meaningful visual storytelling.

The design should feel:
- Organized, compact, and visually balanced
- Refined, approachable, and expressive
- Information-rich without looking cluttered
- Suitable for academic and professional presentations

## 2. Visual Hierarchy

Use four levels of typography:
1. Main title
2. Section heading
3. Body text
4. Supporting labels and annotations

Distinguish levels through size, weight, and color.
Do not rely on color alone.

## 3. Layout Principles

- Establish a consistent grid before placing elements.
- Align related elements along shared edges.
- Keep spacing between modules consistent.
- Prefer compact layouts over excessive empty space.
- Preserve enough whitespace for readability.
- Allow large illustrations to connect information modules.
- Avoid placing every piece of information in identical cards.

## 4. Color System

Use project-specific palettes rather than a fixed palette.

Recommended roles:
- Background color
- Primary text color
- Main theme color
- Secondary theme color
- Subtle surface color
- Accent color

Use accent colors selectively to communicate hierarchy,
categories, and important relationships.

## 5. Shapes and Lines

- Use consistent corner radii within each graphic.
- Keep border weights visually coherent.
- Make important arrows and connections clearly visible.
- Use thin dividers for secondary information.
- Avoid unnecessary shadows, gradients, and decorations.

## 6. Illustrations and Icons

- Illustrations should explain concepts or relationships.
- Keep icon styles consistent within one SVG.
- Prefer recognizable, simplified vector illustrations.
- Use themed illustrations when they improve storytelling.
- Avoid adding icons merely to fill empty space.

## 7. Information Density

- Preserve all essential information.
- Reduce redundant wording before shrinking text.
- Prioritize readable typography.
- Keep related information visually grouped.
- Avoid excessive gaps between connected modules.

## 8. SVG Requirements

- Use native SVG shapes, paths, and text.
- Keep text editable whenever possible.
- Group related elements logically.
- Use meaningful IDs for important components.
- Avoid rasterizing complete layouts.
- Ensure the SVG has a valid viewBox.

## 9. Revision Rules

When modifying an existing SVG:
- Preserve approved visual elements.
- Change only the requested areas when possible.
- Maintain the original layout and style unless asked.
- Never redesign unrelated components.
- Recheck alignment, typography, and connections.

## 10. Quality Standard

Before delivery, verify:
- Content accuracy
- Clear hierarchy
- Consistent alignment
- Appropriate visual density
- Readable text
- No clipping or overlapping
- Valid and editable SVG output
