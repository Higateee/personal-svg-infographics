# Optional local visual references

Add your own permitted reference images here when working locally. No reference artwork is included in the public release; the Skill also works from written rules alone.

Keep original formats. Choose one main visual direction and record what each selected image contributes: overall style, layout, illustration, diagram structure or typography. Exclude failed tests unless explicitly chosen as references.

This directory is ignored by Git except for this README. To publish artwork, first establish permission to redistribute it and document its source, author and applicable license before changing the ignore rule. The project MIT license does not automatically cover material added by users.
